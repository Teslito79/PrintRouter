CorelDRAW files that PrintHub copies into every product item as print.cdr.

blank.cdr         an empty CorelDRAW document (save it once from CorelDRAW, A4, your usual settings).
                  Used for every product that has no file of its own below.

<product>.cdr     optional: your layout template for one product, named after the website's
                  product id, e.g. bcard.cdr (8 business cards per A4 with cut marks).
                  Used instead of blank.cdr for that product.

The copy is made once, when the order arrives. A print.cdr that is already in an
item folder is never replaced. In CorelDRAW, export the finished sheet as
print.pdf into the same folder (CorelDRAW suggests that name, because the file is
called print.cdr), then press Layout done in PrintHub.
