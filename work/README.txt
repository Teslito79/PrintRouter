WORK FOLDER - notes and reports between home and the work PC

notes\    Work notes from the planning window (home PC). They reach the work PC
          through GitHub: PrintRouter downloads them every time it starts.
          At work, open the Work PC chat (Claude, folder C:\PrintRouter\ADMIN)
          and type go: it goes through the oldest note with you, step by step.

reports\  The Work PC chat writes its report here when a note is finished (or
          stopped), with any screenshots or test PDFs, and uploads only this
          work folder. The planning window reads the reports at home.

done\     Finished notes. The Work PC chat moves each note here when its report
          is written.

files\    Files a note needs, for example test prints (PDF sheets).
