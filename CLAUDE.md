## What it is

Windows desktop app, Python 3.14 + Tkinter, about 3,500 lines. Walk-in orders are priced, placed and printed from the Walk-in / Orders screens (2026-11-17); the app converts files to PDF, picks a Ricoh copier by rules (or by hand), sends with per-job driver settings through `driverprint.py` (PrintTicket to DEVMODE, pdfium drawing via ctypes, nothing saved to printer defaults) and prints a price receipt on the XP-80C thermal printer.

CorelDRAW templates (2026-11-06): `templates/<W>x<H>.cdr` per product size in mm; `printhub.choose_template` picks `<product id>.cdr`, then `cut_mm` WxH, then HxW, then `blank.cdr`, and Options.txt / the details show which. Size table: `PRINTHUB_SPEC.md` 3.4. Template choice, pieces per sheet, tray lines and the write-once copy live in `product_files.py` (2026-11-17), shared by PrintHub and walk-in orders. Layout done fills in pieces per sheet from `rules.json` `pieces_per_sheet` (size WxH/HxW, A4/A3; Tesla, 2026-11-12), never over a saved value; `Options.txt` names them.

Main menu (2026-11-15; order since 2026-11-19_08): ORCA opens on `mainmenu.py`: Walk-in (`walkin_screens.py`, Orders inside it), Inventory management (`inventory_screens.py`), Data (`toners.py`), PrintHub, Counter (`counter.py`), Prices (`costs.py`), Settings (`settings_screen.py`); `app.py` only starts it; one window at a time, Back on every screen, closing the menu quits. Counter adds up `print_log.csv` (columns since 2026-11-15: source, order, product, quantity, sheet size, color sides, bw sides, paper name; old lines still read). Prices holds the shop's costs (not `prices.json`) in `costs.json`, behind a password whose salted hash is in `prices_password.json` (delete it to reset); both local and gitignored. Costs show only in Counter and Prices, never in PrintHub or Walk-in. Counter's **Export PDF** (`counter_pdf.py`, pypdfium2 + embedded Arial, no new package) writes the period showing as a white A4 PDF, with Include costs / Include the list of jobs remembered in `counter_export.json` (local, gitignored).

Data (toners, 2026-11-16; called Toners until the rename the same day): fifth menu button, `toners.py` (module, class and local file names unchanged). Reads each copier's counters and toner levels over SNMP (own small v2c/v1 code, read-only, `public`) at start and every 10 min, one thread per copier, short timeouts; address from the queue's TCP/IP port or typed per copier. A toner level the copier reports as -2 ("unknown"; the IM C3000's empty yellow, 2026-11-19_06) counts as 0 and shows "Empty" in red (0 does too); -3 shows "Some left"; -1 and a toner with no row stay "not given"; the copier's own value is kept in `toner_state.json` (`toner_raw`) and Copier check shows it ("Empty (copier says unknown, -2)"). A level rising 30+ points = a toner change ("automatic" / "found at start"), or **Toner replaced** by hand; same toner within 24 h counts once. History: copies by the toner taken out (black: total counter; colours: colour counter, else total with a note) and averages. **Copier check** writes `copier_check.txt`. Local, gitignored: `toner_log.csv`, `toner_state.json`, `toner_settings.json`, `copier_check.txt`. Not yet tested on the real copiers. Spare toners per copier and colour ("Spare: 2", Stock… with − / + / typed count and minimum, red "Order more" / "None left", red dot on the menu's Data button); each recorded change takes one, removing it gives it back; `toner_stock.json` and `toner_stock_log.csv`, local and gitignored.

Inventory management (2026-11-19_03, Tesla: "track the inventory of the physical shop, including paper and every other item in there"): a menu button, second since 2026-11-19_08, with a red dot while an item is under its minimum (`inventory.py`: data and rules; `inventory_screens.py`: the screens). Local, gitignored, written safely: `inventory.json` (items: id, name (unique), category, barcodes (each belongs to one item), unit, stock and minimum in pieces (sheets for paper; may go below 0: "Count it"), sale price EUR (None: not for sale), link, pieces per unit ("5 reams + 120 sheets"), notes) and `inventory_log.csv` (time, item, change, stock, reason, sale).   - **Open file** button opens the customer file (default PDF program / CorelDRAW).
